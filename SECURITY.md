# Security

Report a vulnerability privately: open the **Security** tab of this repository and choose **Report a vulnerability**. Please do not open a public issue for it.

**In scope:** the contact endpoint (`functions/`), the build and check scripts (`scripts/`), and the security headers and CSP the build emits (`static/_headers`). Sample business names, copy, prices, and images are fictional and out of scope.

Only `main` is supported. There is no bug bounty.
