09 / Disclosure

Native Accordions & Disclosures

Semantic <details> and <summary> controls operating without client-side JavaScript.

How do native disclosures work without JavaScript?

The browser natively manages the open/closed state, toggles visibility, updates accessible aria properties, and handles Enter and Space keypresses without executing a single line of client script.

Can disclosures be customized with the brand accent?

Yes. Summary indicators, focus rings, hover backgrounds, and border rules are bound to the root CSS custom properties and adapt automatically to light and dark color schemes.
